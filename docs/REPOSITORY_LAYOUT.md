# Repository Layout

- `core/` shared library, metadata, and watcher logic
- `backend/` local FastAPI service
- `desktop/` native Python/Tkinter client
- `android/` Android Studio client
- `clients/flutter/` future shared Flutter client
- `web/` browser UI
- `db/` SQL schema
- `tests/` automated tests
- `tools/` developer utilities
- `docs/` architecture and project state documentation

Generated caches, databases, personal media, credentials, and build output are excluded.
