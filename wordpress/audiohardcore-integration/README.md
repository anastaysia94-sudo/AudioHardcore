# AudioHardcore WordPress Integration Plugin

Minimal WordPress connector for the AudioHardcore REST API.

## Install

Zip the `audiohardcore-integration/` folder and install it from **Plugins > Add New > Upload Plugin**.

After activation, configure **Settings > AudioHardcore** and enter the base URL of the AudioHardcore API.

Use `[audiohardcore_library]` in a page or post to display live library statistics from the AudioHardcore API.
